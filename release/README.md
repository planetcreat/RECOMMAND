# 플레이 파일 안내

처음 플레이한다면 **[최신 Releases](https://github.com/planetcreat/RECOMMAND/releases/latest)**에서 **PLAY-RECOMMAND.html 하나만 다운로드**하세요. Chrome 또는 Edge로 열면 됩니다. 네 행성·그림·프롤로그·진행 안내가 모두 들어 있습니다.

| 파일 | 내용 |
| --- | --- |
| **PLAY-RECOMMAND.html** | 추천 통합판. 이 파일 하나로 전체 행성을 플레이합니다. |
| RECOMMAND.html | 유온 개별 실행판. |
| SWAEHAE.html | 쇄해 개별 실행판. |
| MUMYEONG.html | 무명 개별 실행판. |
| HWANSEONG.html | 환성 개별 실행판. |

개별 실행판을 사용하면 행성 이동을 위해 네 HTML을 같은 폴더에 두어야 합니다. GitHub의 파일 미리보기는 게임 실행 화면이 아닙니다.

이전 기록은 같은 브라우저·프로필·주소에서 이어집니다. 다운로드한 HTML 안에 개인 저장이 들어 있지는 않습니다. 파일을 바꾸기 전 원래 플레이 주소와 보관 기능을 확인하세요. 자세한 조작·저장·문제 해결은 [프로젝트 README](../README.md)를 참고하세요.
